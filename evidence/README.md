# Learner evidence

Create the reports requested by the issue lessons in this directory. They are
intentionally absent from the starter so the coach does not mark unfinished work
complete. Use the exact filenames and `##` headings from each lesson.

Write concrete observations, commands/results, tradeoffs, and human decisions.
Do not include passwords, access tokens, connection strings containing credentials,
production/customer data, or entire environment dumps.

Azure completion evidence comes from the successful deployment workflow artifact,
not a JSON file you write here. Keep screenshots and reports free of credentials.
